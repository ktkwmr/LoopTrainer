# 記事の内容確認（人間がやる）

記事は Claude が書き、**公開（main へのマージ）の前に人間が内容を確認**します（WEBAPP_BASELINE.md §10-7）。
PR を出すと Cloudflare のボットが PR にプレビュー URL をコメントするので、そこで実際のページを見て確認します（末尾に `/looptrainer/` を付ける）。直したい点は PR のコメントか Claude への指示で伝えてください。

## 毎回見ること

| # | 観点 | 見るところ |
|---|---|---|
| 1 | 事実の正しさ | 耳コピ・練習法・チューニング・カポの説明に間違いや言い過ぎがないか |
| 2 | アプリとの一致 | 記事の説明（ボタン名・手順・初期値）がいまのアプリの動きと合っているか。画面写真が古くないか |
| 3 | 表の内容 | 表は `scripts/pages/practice.mjs` で計算しているので書き間違いはないが、選んだ例（曲の BPM、上げ幅、キーの動かし方）が実際に自然か |
| 4 | 日本語・英語の自然さ | 直訳っぽい言い回し、用語の不統一（速度／テンポ、キー変更／移調、ループ／区間など） |
| 5 | 検索用の文言 | 各記事の `title` と `description`（`scripts/pages/<slug>.mjs` の先頭）が、狙う検索語を含み、内容と合っているか |
| 6 | 権利 | 著作権のある曲名・歌詞・画像を使っていないか（画面写真の音源は `tests/signals.mjs` で作った合成音、ファイル名は架空） |
| 7 | スマホ | 390px 前後の幅で読みやすいか（表は横スクロール） |

## 今回（2026-10-25、記事 5 本の初版）特に見てほしいところ

| # | 記事 | 確認してほしい点 |
|---|---|---|
| A | 使い方ガイド・よくある質問 | 「iPhone は消音モードでも音が出る（iOS 17 以降）」。`navigator.audioSession` を使っているが、対応が始まった iOS のバージョンは Claude の知識で書いた。実機（消音スイッチをオン）で音が出るかと、手元の iOS のバージョンを確認してほしい |
| B | 使い方ガイド | 画面写真の番号（プレイヤー 1〜10、設定 1〜7）と一覧の対応。「インストール」ボタンの出方（ファイルを開いたあと、Chrome・Edge でブラウザがインストールできると判断したときだけ出る） |
| C | 使い方ガイド | 「速い 6/8 の曲は 1 小節の拍数を 2 にすると合うことが多い」。拍の検出が付点 4 分音符を 1 拍と取る場合を想定した書き方。実際の曲で確かめたものではない |
| D | 耳コピのやり方 | 「速度ごとの向いている使い方」の表（90〜100%／70〜80%／50〜60%）は一般的な目安として Claude が決めた。違和感がないか |
| E | 耳コピのやり方 | 「ベースラインはキーを数半音上げてヘッドホンで聞くと聞き取りやすくなることがある」。効果は人や曲による。不要なら削ってよい |
| F | 少しずつ速くする練習法 | 「間違えずに 3 回続けて弾ける速度から始める」「100% のあと 105〜110% で数周弾くと原曲が楽に感じる」は一般的な練習の考え方として書いた。言い過ぎがないか |
| G | キー変更の使い方 | 場面ごとの設定（半音下げの録音に +1、全音下げに +2、カポ 2 の録音をカポなしで −2、カポ 3 の録音にカポ 1 で −2）。考え方は「録音を自分の楽器のほうへ動かす」。向きの間違いがないか |
| H | キー変更の使い方 | 「ロックやメタルの録音には半音下げチューニングのものが多い」「1〜2 半音なら違和感はほとんどない」は一般的な傾向として書いた |
| I | 全体 | 実際の曲での拍・小節の検出はまだ試していない（合成音で ±6 ms 以内、小節の頭も合成音で確認）。記事の「コードが変わる位置とベース・キックの強さから推定」という説明と、実際の曲での当たり具合 |

## 確認が終わったら

1. 直す点があれば Claude に伝える（Claude が直して PR を更新 → もう一度確認）。
2. 問題なければ「マージして」と伝える。マージ後、本番に反映されたかを Claude が確かめる。
3. 公開後、Search Console でサイトマップ `https://ktkwmr.com/looptrainer/sitemap.xml` を再送信する（ページが 10 増えるため）。
4. トップページ（`ktkwmr/ktkwmr.com` の `home.mjs`）の Loop Trainer のカードにガイド記事の一覧を足す PR を Claude が出す（WEBAPP_BASELINE.md §2-16）。
